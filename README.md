# 🏠 House Wiring Analysis and Load Distribution

## 📖 Project Overview

This project presents the design and analysis of a complete residential house wiring system. The objective is to model, simulate, and analyze the electrical distribution network of a house, including power calculations, load distribution, circuit protection, and UPS backup integration.

The project was developed as part of the Circuit Engineering Project (CEP) and utilizes MATLAB and Multisim to verify electrical calculations and simulate the operation of the wiring network.

---

## 🎯 Objectives

- Design a residential electrical wiring system.
- Calculate electrical load requirements for each room.
- Analyze current, voltage, resistance, and power consumption.
- Simulate the electrical network using Multisim.
- Verify power delivered and power absorbed.
- Evaluate UPS backup operation during power outages.
- Ensure safe and efficient load distribution.

## 🔢 Calculations

The following parameters were calculated:

- Current (I)
- Voltage (V)
- Resistance (R)
- Power (P)
- Total Load Demand

Using:

\[
P = V \times I
\]

\[
I = \frac{P}{V}
\]
